# Codex Context Widget

Компактное окно для macOS с тремя колонками. Для каждого неархивированного пользовательского чата Codex видны название и ID, суммарное число потраченных токенов и процент заполнения контекста. Сверху — самые заполненные чаты. Данные обновляются каждые пять секунд.

## Запуск

Нужны macOS 13 или новее и Swift из Xcode Command Line Tools.

```sh
./build.sh
open "build/Codex Context.app"
```

Приложение можно перенести в Applications. Оно читает локальную базу Codex в режиме read-only и соответствующий журнал каждого чата. По умолчанию каталог данных — `~/.codex`, при запуске из окружения с `CODEX_HOME` используется указанный каталог.

## Как читать цифры

- **Потрачено токенов** — накопительный счётчик `threads.tokens_used` за весь чат.
- **Контекст** — `last_token_usage.total_tokens / model_context_window × 100` по последнему записанному замеру этого чата. После сжатия до нового замера отображается прочерк. При отсутствии журнала или размера окна тоже отображается прочерк.

Основан на [Token Meter](https://github.com/SergioChan/token-meter), лицензия MIT.

Во вкладке **Джобы** видны локальные запуски из `~/.local/state/harness/ticket-lifecycle/`. Выберите тикет, чтобы открыть расписание его таймера, текущий шаг, последние попытки и ссылки из журнала переходов. Вкладка обновляется каждые две секунды. Старые запуски показывают сохранённый этап и ссылки. Время следующего опроса и история действий появляются при запуске координатора с поддержкой `activity.json` и `timer-*/schedule.json`. Учитываются таймеры самого координатора.
